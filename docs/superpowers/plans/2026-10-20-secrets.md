# Secrets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a zero-dependency, leak-resistant `Secret` credential holder (masked repr/str, not JSON-serializable, `.reveal()` to read) plus a documented no-store guarantee.

**Architecture:** A `Secret` value type in `labjury.secrets` using `__slots__` so the value lives nowhere visible and is readable only via `reveal()`. Masked `__repr__`/`__str__`, value-based `__eq__`/`__hash__` (only against another `Secret`), not JSON-serializable. In core, top-level re-exported. No engine or plugin-contract change; `AuditEvent`/`ProvenanceRef` unchanged.

**Tech Stack:** Python 3.11+, stdlib only, pytest.

**Spec:** `docs/superpowers/specs/2026-10-20-secrets-design.md`

## Global Constraints

- Core `dependencies = []`; stdlib-only; mechanism in `labjury.secrets`; core never imports `labjury.contrib`.
- No public plugin contract change; no `AuditEvent`/`ProvenanceRef` change.
- The underlying value is readable only via `reveal()` — no attribute, property, repr, str, or serializer exposes it.
- TDD throughout; commit per task.

## Review Focus

- Value never appears in `repr`, `str`, or an f-string — pinned in Task 1 (`test_secret_masks_value`).
- `reveal()` returns the exact original value — pinned in Task 1 (`test_secret_reveal_returns_value`).
- `json.dumps(Secret(...))` raises `TypeError` (fails loud) — pinned in Task 1 (`test_secret_not_json_serializable`).
- Equality/hash by value, and `Secret("k") == "k"` is `False` — pinned in Task 1 (`test_secret_equality_and_hash`).

### Task 1: `Secret` leak-resistant holder

**Files:**
- Create: `src/labjury/secrets.py`
- Test: `tests/test_secrets.py`

**Interfaces:**
- Produces: `labjury.secrets.Secret(value: str)` — `reveal() -> str`; masked `__repr__`/`__str__`; `__eq__` by value against another `Secret` only (else `NotImplemented`); `__hash__` by value; not JSON-serializable.

- [ ] **Step 1: Write the failing tests** in `tests/test_secrets.py`

```python
import json
import pytest
from labjury.secrets import Secret

def test_secret_masks_value():
    s = Secret("sk-supersecret")
    assert "sk-supersecret" not in repr(s)
    assert "sk-supersecret" not in str(s)
    assert "sk-supersecret" not in f"{s}" and "sk-supersecret" not in f"{s!r}"

def test_secret_reveal_returns_value():
    assert Secret("sk-supersecret").reveal() == "sk-supersecret"

def test_secret_not_json_serializable():
    with pytest.raises(TypeError):
        json.dumps(Secret("sk-supersecret"))

def test_secret_equality_and_hash():
    assert Secret("k") == Secret("k")
    assert Secret("k") != Secret("other")
    assert (Secret("k") == "k") is False
    assert hash(Secret("k")) == hash(Secret("k"))
    assert len({Secret("k"), Secret("k")}) == 1
```

- [ ] **Step 2: Run the tests to verify they fail**

Run: `pytest tests/test_secrets.py -v`
Expected: FAIL — `No module named 'labjury.secrets'`.

- [ ] **Step 3: Implement `Secret` in `src/labjury/secrets.py`**

Class with `__slots__ = ("_value",)`; `reveal` returns `self._value`; `__repr__` returns `"Secret('***')"`, `__str__` returns `"***"`; `__eq__` returns `self._value == other._value` when `other` is a `Secret` else `NotImplemented`; `__hash__` returns `hash(self._value)`. Module docstring: leak-resistance (repr/str/serialize), not encryption; `reveal()` returns plaintext.

- [ ] **Step 4: Run the tests to verify they pass**

Run: `pytest tests/test_secrets.py -v`
Expected: PASS (all of Step 1).

- [ ] **Step 5: Commit**

```bash
git add src/labjury/secrets.py tests/test_secrets.py
git commit -m "feat: zero-dep leak-resistant Secret holder"
```
